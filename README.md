# 我的世界：起床战争 (Minecraft Bedwars) - 布吉岛风格 1v1

这是一个基于 **Three.js WebGL 3D 引擎** 与 **原生第一人称视角** 制作的 Minecraft 起床战争（Bedwars）网页游戏。完整还原了类似布吉岛 / Hypixel 的核心玩法、第一人称体素手感与智能人机对战系统。

---

## 🎮 快速启动游戏

### 🌐 方式 0：在线直接玩（免安装推荐）
👉 **在线试玩地址：[https://melodyless.github.io/BedWars/](https://melodyless.github.io/BedWars/)**

### 方式 1：双击批处理脚本（本地离线）
在项目目录下直接双击运行：
👉 `start_game.bat`

### 方式 2：Python 命令行运行
在项目目录下打开终端运行：
```bash
python run.py
```
运行后会自动在浏览器中打开游戏页面：`http://localhost:8000/index.html`。

## 🕹️ 键盘与鼠标操作指南

| 按键 / 操作 | 功能描述 |
| :--- | :--- |
| **W / A / S / D** | 第一视角前后左右移动 / 奔跑 |
| **鼠标移动** | 转动第一人称视角（锁定指针） |
| **空格键 (Space)** | 跳跃 |

| **鼠标左键** | 挥剑攻击敌人（带击退与伤害） / 长按破坏方块与敌人的床 |
| **鼠标右键 (可长按)** | 放置方块 / **长按右键朝边缘走即可自动连续搭桥** / 对准村民商人打开商店 / 吃金苹果 / 发射火焰弹 |

## 🏰 核心玩法机制（原版布吉岛风格）

1. **浮空岛地图 (Floating Islands)**：
   - **红队基地（玩家）**：配有红床、铁/金资源生成器、村民商店 NPC、升级商人。
   - **蓝队基地（人机）**：配有蓝床、铁/金资源生成器、村民商店 NPC。
   - **中心中岛 (Emerald Island)**：配有绿宝石生成器与中心凉亭。
   - **两侧钻石岛 (Diamond Islands)**：定时喷吐钻石资源。
   - **虚空 (Void)**：跌落虚空直接扣血阵亡。

2. **智能人机 AI (High-IQ Autonomous Bot)**：
   - **自动去商店消费进阶**：收集铁金后会走向村民商人，自主购买**铁剑/钻石剑**、升级**铁盔甲/钻石盔甲**、购买**剪刀**、**金苹果**与**火焰弹**，并实时更换全身 3D 装备外观！
   - **绝对不摔虚空的搭桥技术**：内置物理潜行边缘锁（Edge Guard），走在 1 格宽桥梁上**绝不会失足滑落**，遇到虚空停止并稳步铺设羊毛方块推进。
   - **自主床防加固**：购买羊毛后自动将蓝队床铺用羊毛严实包裹防护。
   - **中岛抢绿宝石**：向中岛推进抢夺绿宝石，快速进阶钻石装备。
   - **战术道具使用**：
     - 残血（< 9 HP）时会后撤**吃金苹果瞬间回血**！
     - 远距离发现玩家时会**发射火焰弹轰炸**摧毁玩家桥梁与造成爆炸击退！
     - 攻入红队基地时，若床有羊毛防守会使用剪刀秒拆床防！
   - 进攻状态：直奔红队的床，挖掘破坏床铺，并追击最终击杀！

3. **床机制与最终击杀 (Bed & Final Kill)**：
   - 床完好时：阵亡后进入 **5 秒复活倒计时**，满血在基地复活。
   - 床被破坏后：屏幕弹出震颤大标题与凋灵咆哮音效，失去复活机会！
   - 敌方床破坏后击杀敌方：触发 **最终击杀 (Final Kill)**，赢得游戏胜利！

4. **村民交易商店 (Villager Shop)**：
   - **方块**：羊毛（4 铁）、橡木木板（4 金）、末地石（24 铁）、黑曜石（4 绿宝石）。
   - **武器**：石剑（10 铁）、铁剑（7 金）、钻石剑（4 绿宝石）。
   - **盔甲**：锁链甲（40 铁）、铁盔甲（12 金）、钻石甲（6 绿宝石）。
   - **工具**：剪刀（20 铁，快速剪羊毛）、木镐、铁镐、钻石镐。
   - **实用道具**：金苹果（快速回血）、火焰弹（远程爆炸破坏羊毛）、末影珍珠。

5. **音效与材质 (Audio & Pixel Textures)**：
   - 内置 Web Audio API 实时合成音效（受伤挨打声、拾取物品叮咚声、挥剑风声、放置方块声、破坏方块声、拆床凋灵咆哮声、胜利号角）。
   - 100% 独立离线运行，无需外网或任何第三方模型包。
